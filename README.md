# Roadmap Studio v0.7

## Added
- Compact category badge instead of full-height category color.
- Fiscal-year display using September through August.
- Global defaults plus per-roadmap overrides.
- One to four FYs, Calendar Year, and Custom date views.
- Collapsible Done group with Closed Complete, Closed Incomplete, and Closed Skipped.
- Done-only view option.
- Persistent palette and State order in browser localStorage.
- One-line future out-of-view summary, grouped by future FY; past out-of-view records are not called out.
- Full historical records remain in roadmap_data.json and can be viewed by selecting an earlier FY or custom date range.

Upload all contents to the GitHub repository root and preserve `.github/workflows/deploy.yml`.

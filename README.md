# Roadmap Studio v0.9
Built on the accepted v0.8/v0.6 Gantt layout.

- Single-category pillar roadmaps remove the redundant category block; OTIS keeps department categories.
- SWIS roadmap groups by Campus, then State.
- FC portfolios group by Campus, then State.
- Campus portfolios group by Pillar, then State.
- Portfolio items deduplicate by ServiceNow number.
- Bars clipped by the start of the selected view use a squared, shadowed left edge.
- ServiceNow button sits immediately below Description.
- Clicking outside a drawer closes it; X remains available.
- Dashboard metric cards open all-pillar filtered roadmaps, including Closed.
- Main navigation spans the page with light colors; pillar buttons use three columns.
- Header changed to SIS Portfolio Overview and Campus Portfolio uses a landmark icon.
